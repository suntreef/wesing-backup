# 全民K歌备份 · 设计规范（Design Spec）

> 本文档是全部界面的唯一设计依据。改任何界面先读这里；新增组件从这里的令牌和规则出发。
> 参考底座：Apple《Designing Fluid Interfaces》/《The Details of UI Typography》
> （工程化转译参考 Emil Kowalski 的 apple-design skill）+ Keep it usable（不能影响使用）。

## 0. 三个「面孔」，一套骨架

产品有三个界面，共用同一套骨架规则（字体栈、动效时长、按压反馈、无障碍降级），
但各有自己的强调色与气质——场景不同，气质允许不同：

| 界面 | 文件 | 强调色 | 气质 | 密度 |
|------|------|--------|------|------|
| 管理工作台 | `static/index.html` | 品牌蓝 `--accent #4066f0` | 冷静、工具感 | 紧凑 |
| 朋友盲盒 | `core.py → GUEST_TEMPLATE` | 盲盒金 `--gold #ffd76a` | 节日、期待感 | 舒展 |
| 歌单预览 | `core.py → PAGE_TEMPLATE` | 复古金 `#ffd76a` + 唱片美学 | 怀旧、收藏感 | 舒展 |

跨页一致的部分（用户感知为「同一个产品」）：
同一系统字体栈、同一动效时长体系、同一按压/焦点反馈、同一无障碍降级策略。

## 1. 设计令牌（Tokens）

### 1.1 颜色

管理页令牌定义在 `:root`（并带 `html[data-theme]` 显式覆盖）；
盲盒页令牌定义在 `body`（暗色默认）与 `body.light`（浅色）。

| 令牌 | 管理页 | 盲盒页（暗） | 盲盒页（亮） | 用途 |
|------|--------|--------------|--------------|------|
| 背景 | `--bg` | `--gb-bg` | `--gb-bg` | 页面底 |
| 卡片 | `--surface` | `--gb-surface` | `--gb-surface` | 卡片底 |
| 卡片-次级 | `--surface2` | `--gb-surface2` | `--gb-surface2` | 输入框/行底 |
| 主文字 | `--text` | `--gb-text` | `--gb-text` | 正文 |
| 次文字 | `--text2` / `--text3` | `--gb-text2` | `--gb-text2` | 说明/时间 |
| 描边 | `--line` / `--line2` | `--gb-line` | `--gb-line` | 卡片/分隔 |
| 强调 | `--accent` | `--gold` | `--gold` | 主按钮/高亮 |
| 成功/警告/错误 | `--ok/--warn/--err` | `--ok/--warn/--err` | 同 | 状态 |

规则：
- **旧令牌别名必须保留**：`--card/--red/--blue/--green` 是 JS 动态弹窗的依赖，
  删除别名 = 弹窗底色变透明（v1.12.26 修过的回归，不许再犯）。
- 新 JS 弹窗一律用 `var(--card)/var(--text)/var(--line)` 这套别名写，不直接用新名。

### 1.2 字号（Type Scale）

| 级别 | 大小 | 用途 | 字距 |
|------|------|------|------|
| display | 22–44px clamp | 页面主标题 | `-0.02em` |
| h1 | 17–19px | 区块标题 | `-0.015em` |
| h2 | 13.5px | 卡片标题 | `-0.005em` |
| body | 13.5–15px | 正文/输入 | `0` |
| meta | 11–12px | 时间/说明 | `0` |
| micro | 10–10.5px | 角标/胶囊 | `+0.04em`（大写微标签） |

规则：字距随字号走（大字收紧、小字放宽），全站字体栈统一为系统栈
（`-apple-system, "SF Pro SC", "PingFang SC", "Microsoft YaHei", sans-serif`），
开启 `font-optical-sizing: auto`。

### 1.3 圆角（Radius）

| 令牌 | 值 | 用途 |
|------|----|----|
| `--r-s` | 9–10px | 小按钮/输入框/胶囊 |
| `--r-m` | 11–13px | 卡片内组件/行 |
| `--r-l` | 14–18px | 卡片 |
| `--r-hero` | 22–26px | 盲盒页主卡（今日盲盒） |

### 1.4 间距（Spacing）

4px 网格：`4 / 8 / 12 / 16 / 24`。卡片内边距 16–24px，区块间距 13–18px，
页面左右留白 20px（手机 13–14px）。

### 1.5 动效（Motion）

| 令牌 | 值 | 用途 |
|------|----|----|
| `--dur-fast` | 100–150ms | 按压反馈（按下即响应，不等释放） |
| `--dur-med` | 180–300ms | 悬停/展开/主题切换 |
| `--dur-slow` | 300–400ms | 面板进出 |

规则：
- 动画只动 `transform` / `opacity`（合成器友好）。
- 按压反馈 = `:active` 缩放 0.94–0.97 + 100ms ease-out，**全站交互元素必须覆盖**。
- 明暗主题切换 0.3s 渐变，避免亮度跳变。
- **无障碍三态**（三页必须都有，v1.12.25 起已落地）：
  - `prefers-reduced-motion`：装饰动画瞬时等效，彩带/背景画布隐藏；
  - `prefers-reduced-transparency`：毛玻璃换实色底；
  - `prefers-contrast: more`：边框与次级文字提对比度。

### 1.6 触感（Haptics）

只在**因果明确的关键时刻**用（拆开今日盲盒），`navigator.vibrate([28,40,28])`。
全站最多 1–2 处，过度反馈会训练用户忽略所有反馈。

## 2. 组件状态

每个可交互元素必须有完整状态链：

`默认 → 悬停(hover) → 按下(:active, 即时) → 焦点(:focus-visible, 键盘) → 禁用`

- 悬停：边框/底色变化 + 轻微位移（≤3px）；
- 按下：缩放 0.94–0.97，100ms；
- 焦点：键盘导航时显示 2px `--accent` 外环（鼠标点击不显示）；
- 禁用：`--text3` 底色，no-transform。

## 3. 图标

- 管理页：一律 SVG 线性图标（1.8 描边、圆头、跟随 currentColor），禁止 emoji；
- 盲盒页：允许 emoji（节日气质的一部分），但功能性按钮用 SVG。

## 4. 弹窗（Modal）

- 遮罩 `rgba(0,0,0,.6)` + 弹窗卡片**不透明** `var(--card)`（别名令牌）；
- 手机 ≤640px：卡片宽 92%，内容区 `max-height:88vh` 滚动；
- 列表行允许换行（`flex-wrap:wrap`），昵称列保底宽度，操作钮 `flex:none`；
- 卡片标题 `white-space:nowrap`，副标题换行到下一行（不挤标题）。

## 5. Service Worker / 页面新鲜度

- 页面（navigate 请求）：**网络优先**，断网才回退离线缓存（盲盒数据嵌在 HTML 里）；
- 静态资源/封面：先缓存后更新（stale-while-revalidate）；
- 接口、音频 Range、大音频：SW 不插手；
- 每次改 SW：缓存名必须升级（v3 → v4 …），老用户自动换新。

## 6. 验收清单（每次改界面过一遍）

- [ ] 桌面 + 手机（390px）双视口截图过目；
- [ ] 明暗两主题都看过；
- [ ] 弹窗在手机上不透底、列表行不挤压；
- [ ] 键盘 Tab 能看到焦点环；
- [ ] 系统开启「减弱动态」后界面仍可用、无跳动；
- [ ] 单元测试全绿。
